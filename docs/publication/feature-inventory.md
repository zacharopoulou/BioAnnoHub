## Practical status summary

The core execution and output workflow is implemented. The paper's main risk lies in the distinction between *common fields* and *semantically lossless interoperability*: the current schema supports useful side-by-side inspection, but does not fully preserve every tool's label and normalization namespace/candidate information. Verification is also strongest at the adapter-unit level, not across fresh installs and live services.
