# ChEBI corpus - local benchmark data

The ChEBI corpus has **no train/test split**. It has three parts, and each
one is committed to this repo as its own file, used for testing annotators.
Nothing is left out via `.gitignore`. To regenerate them locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/chebi.py
```

That downloads the corpus from Hugging Face (`bigbio/chebi_nactem`, one
config per part) into this directory. The loader gets the original files
from NaCTeM (`http://www.nactem.ac.uk/chebi`).

| File | Content | Documents | Mentions |
|---|---|---|---|
| `chebi_fullpaper.jsonl` | full papers | 100 | 41,315 |
| `chebi_abstracts_ann1.jsonl` | PubMed abstracts, annotator 1 | 199 | 5,551 |
| `chebi_abstracts_ann2.jsonl` | the same abstracts, annotator 2 | 199 | 5,614 |

The ChEBI corpus (Shardlow et al., 2018) is about chemicals and
metabolites, especially natural products. No normalization. It also has
relations (Associated_With, Binds_With, Isolated_From, Metabolite_Of),
which are kept in the files but are not needed for NER.

It annotates 6 entity types:

| Type | Examples |
|---|---|
| Chemical | glucose, taurine, GSH |
| Metabolite | masoprocol, curcumin, PGE2 |
| Protein | P450, GST, and generic words such as enzyme, protein |
| Biological_Activity | inhibitor, metabolism, binding |
| Species | human, rat, patients |
| Spectral_Data | mass spectrometry, 1H NMR |

The full papers also have 3 `Chemical_Structure` mentions.

## Notes

- **The abstracts were annotated twice.** Annotators 1 and 2 worked
  independently on the same 199 abstracts and agree exactly (same span and
  type) on 4,765 mentions, about 85%. Neither version is the official one,
  so both are kept. Scores on the two versions show how much a result
  depends on who annotated the text. The full papers were annotated once.
- **Offsets are trimmed.** About 1% of the entity spans in the original
  files include extra spaces at the end (the offsets cover `enzyme  `
  while the mention is `enzyme`). An annotator that tags `enzyme` would be
  scored wrong under strict matching, so the script moves those offsets in
  to the first and last non-space character. After this, every mention
  matches its text.
- **Chemical and Metabolite overlap.** The same substance (for example
  *acetate*) can be a `Chemical` or a `Metabolite` depending on its role in
  the text. For a chemical tagger, both types usually count as chemicals.
- **Generic words count.** `Protein` includes words such as *enzyme*, and
  `Species` includes *patients*.
- 11 abstracts have no annotations. They are kept, because any entity an
  annotator finds in them is a false positive.
- `chebi_fullpaper.jsonl` is large (7.2 MB).

## Known training overlap

- **BENT** `BENT-PubMedBERT-NER-Chemical`: its model card lists the ChEBI
  corpus ("Metabolite", "Chemical") with **train, dev and test** sets. The
  corpus has no official split, so BENT made its own and has seen at least
  part of these documents. Its scores here are not a fair test.

`CHEBI_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/chebi_analytics.py` and documents each part (counts,
entity types, normalization coverage, top mentions).
