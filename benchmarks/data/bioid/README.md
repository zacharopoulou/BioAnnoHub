# BioID - local benchmark data

BioID (BioCreative VI Bio-ID track) has **no splits** in the released
data: it is the official training release, `BioIDtraining_2`. The
shared-task test set was never published there. So the whole corpus is in
`bioid.jsonl`, which is committed to this repo and used for testing
annotators, and nothing is left out via `.gitignore`. To regenerate it
locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/bioid.py
```

The script uses the Hugging Face loader (`bigbio/bioid`, config
`bioid_bigbio_kb`), which is **broken** in four ways. The script fixes each
one:

1. **The download link is dead.** The loader downloads the data from the
   BioCreative website, which now blocks every request. The Internet
   Archive saved a copy of the same file (`BioIDtraining_2.tar.gz`) on
   25 July 2022, so the script downloads it from there.
2. **Most annotations were thrown away.** Each figure caption has several
   annotated entities (about 7 on average), but a bug in the loader kept
   only the last one per caption. That turned 102,717 annotations into
   13,573. The script fixes the bug and keeps all of them.
3. **The loader crashes with the newer pandas.** It was written for an
   older version of pandas, so the script switches pandas back to its
   older behavior while the loader runs.
4. **Some entities got the wrong type.** BioID links cell parts such as
   mitochondria, nucleus or ER to the GO database, and the loader labels
   everything linked to GO as `gene`. The script labels them
   `subcellular` instead, which is the label BioID itself uses for cell
   parts.

Each row is one **figure-panel caption**, not an article: 13,697 captions
from 570 PMC articles. `document_id` is the PMC article ID, so it repeats
across rows; the row `id` is the unique caption key.

BioID has 13 entity types: protein, gene, chemical, species, cellline,
anatomy, cell, subcellular, molecule, tissue, rna, organism, assay.
Normalization depends on the type (UniProt, NCBI Gene, ChEBI, PubChem,
NCBI Taxonomy, Cellosaurus, Uberon, CL, GO, Rfam, CORUM, BAO). Mentions
typed molecule, tissue or organism, and some protein, gene, cell and
subcellular mentions, have no ID. No relations.

Note: 10 mentions (0.01%) have an end offset one character too long, so
the span includes a trailing space or period. This comes from the original
`annotations.csv` and is left as is.

`BIOID_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/bioid_analytics.py` and documents the corpus shape
(captions, articles, entity types, normalization coverage, top mentions).
On a Windows console that is not UTF-8, run it with
`PYTHONIOENCODING=utf-8`, because some mentions contain Unicode hyphens.
