# CRAFT - local benchmark data

Only `test.jsonl` is committed to this repo. It is the official held-out
evaluation split, used for testing annotators.

`train.jsonl` and `validation.jsonl` are intentionally **not** shipped here
(see `.gitignore`). Anyone who needs them can regenerate the full corpus
locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/craft.py
```

That builds all three splits with the Hugging Face loader (`bigbio/craft`,
config `craft_bigbio_kb`) from CRAFT v5.0.2
(`https://github.com/UCDenver-ccp/CRAFT`). The split is the official one
from CRAFT itself (`articles/ids/craft-ids-{train,dev,test}.txt`): 60
train, 7 validation and 30 test articles.

The loader does not work on Windows as published, and the script fixes two
problems:

1. **The download cannot be unpacked.** A few files in the CRAFT archive
   have very long paths, and inside the Hugging Face cache folder they go
   over the Windows limit of 260 characters. Unpacking stops early and most
   annotation folders are missing. The script downloads the archive itself
   and unpacks only the files the loader uses, whose paths are short.
2. **Wrong text encoding.** The article texts are UTF-8, but the loader
   opens them with the computer's default encoding (cp1253 on a Greek
   Windows PC), which garbles special characters or crashes. The script
   makes the loader read them as UTF-8.

The result is identical to the earlier `benchmarks_exp` version of this
file, and every entity offset matches the text.

## What is annotated

CRAFT documents are **full-text PMC articles** (about 40,000 characters
each), mostly about mouse genetics. Every mention is linked to a concept in
one of 11 ontologies, and the entity **type is the ontology name**, not a
regular entity type:

| Type | What it covers | Examples |
|---|---|---|
| PR | proteins and genes (Protein Ontology) | Pten, Sox1, Sirt1 |
| CHEBI | chemicals | glucose, Ca2+, estrogen |
| NCBITaxon | organisms | mice, human, animals |
| CL | cell types | neurons, ES cells |
| MONDO | diseases | tumor, colitis |
| UBERON | anatomy | embryo, brain, tissue |
| SO | sequence features (not gene names) | gene, allele, exon, loxP |
| GO_CC | cell parts and complexes | cilia, nuclei, antibody |
| GO_BP | biological processes | expression, regulated |
| GO_MF | molecular functions | hybridization, annealing |
| MOP | molecular processes | acetylated, oxidation |

Notes for evaluation:

- Only some types match what NER annotators produce: PR for genes and
  proteins, CHEBI for chemicals, NCBITaxon for species, CL for cell types
  and MONDO for diseases. GO_BP, GO_MF and MOP are mostly verbs and
  process words (such as *expression*), which normal NER tools do not tag.
- SO is **not** a gene type. It marks words such as *gene* or *allele*,
  not gene names; gene names are PR.
- CRAFT annotates concepts very completely, including common words like
  *mice* or *embryo*, so recall is hard to reach.
- 682 test mentions are discontinuous (several pieces of text, joined by
  ` ... ` in `text`).
- The same text can carry more than one type (23 test spans), and mentions
  of different types can overlap.

`CRAFT_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/craft_analytics.py` from a full local download and
documents the entire corpus shape (counts, entity types, normalization
coverage, top mentions), even though only `test.jsonl` lives here.
