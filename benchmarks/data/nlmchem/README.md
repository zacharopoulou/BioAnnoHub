# NLM-Chem - local benchmark data

Only `test.jsonl` is committed to this repo. It is the official held-out
evaluation split, used for testing annotators.

`train.jsonl` and `validation.jsonl` are intentionally **not** shipped here
(see `.gitignore`). Anyone who needs them can regenerate the full corpus
locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/nlmchem.py
```

That downloads all three splits from Hugging Face (`bigbio/nlmchem`,
config `nlmchem_bigbio_kb`) into this directory. The Hugging Face loading
script parses BioC XML, so it needs the `bioc` package, which is part of
the `benchmarks` extra.

NLM-Chem has one entity type (Chemical) with MeSH normalization. No
relations.

Note: unlike the other benchmarks here, NLM-Chem documents are **full-text
PMC articles**, not abstracts. Each document is split into many passages
(title, abstract, section titles, paragraphs, figure and table captions),
so documents are long and annotator runs over this corpus take much longer
than over BC5CDR or NCBI Disease. Some mentions are normalized to more than
one MeSH ID, and a small number have no ID.

`NLMCHEM_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/nlmchem_analytics.py` from a full local download and
documents the entire corpus shape (counts, document length, passage types,
entity types, normalization coverage, top mentions), even though only the
test split lives here.
