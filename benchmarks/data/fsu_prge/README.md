# FSU_PRGE - local benchmark data

FSU_PRGE has **no train/test split**: it is one corpus of 3,308 abstracts.
So the whole corpus is in `fsu_prge.jsonl` (13 MB), which is committed to
this repo and used for testing annotators, and nothing is left out via
`.gitignore`. To regenerate it locally:

```
uv run python benchmarks/scripts/fsu_prge.py
```

No extra dependencies are needed. The corpus is not on Hugging Face, so the
script downloads release v1.1 from JULIE Lab
(`https://julielab.de/downloads/resources/fsu_prge_release_v1_1.tgz`) and
converts it.

FSU_PRGE (FSU PRotein GEne corpus, JULIE Lab Jena, supervised by Udo Hahn)
has 3,308 PubMed abstracts with 59,514 gene and protein mentions. No
normalization, no relations.

## How the file is built

The release has MMAX2 annotation projects plus an IOB export (one token
and tag per line). The script reads the IOB export. IOB has no character
offsets, so the text is rebuilt the same way as for JNLPBA: tokens are
joined with single spaces, and the B-/I- tags are merged into one entity
per mention with real character offsets into that rebuilt text. Annotators
therefore see tokenized text such as `ERK1 / 2` instead of the original
spacing. Every offset matches the rebuilt text.

Each row also has a `subcorpus` field (see below).

## Entity types

| Type | Meaning | Examples |
|---|---|---|
| protein | a single protein or gene | IFN-gamma, IL-6, p53 |
| protein_familiy_or_group | a family or group of proteins | cytokines, kinase, transcription factor |
| protein_complex | a complex of several proteins | NF-kappaB, RNA polymerase |
| protein_variant | a variant, such as an allele | HLA-B27, IFN-alpha2c |
| protein_enum | a short enumeration of several proteins | ERK1 / 2, Cdk4 / 6 |

`protein_familiy_or_group` keeps the original spelling from the corpus
(with the typo). For a gene or protein tagger, all 5 types together are
the proteins.

## Subcorpora

The corpus is a union of 11 document sets. Some are re-annotated
documents from other corpora, which matters for overlap:

- `Genes_genetag1` and `Genes_genetag2` (1,135 abstracts) are **samples
  from GeneTag**, the corpus that BC2GM was built from, so some of their
  text may also be in BC2GM.
- `Genes_LLL_Aimed` includes documents from the LLL and AIMed corpora.
- The others were selected for this corpus, for example to cover proteins
  in the PIR or KIR databases, or E. coli proteins.

The per-subcorpus counts are in `FSU_PRGE_ANALYTICS_SUMMARY.md`.

## Notes

- 403 abstracts (12%) have no annotations. They are kept, because any
  protein an annotator finds in them is a false positive.
- Release v1.1 fixed some broken MMAX2 projects from v1.0 and removed one
  document without annotations.

## Known training overlap

- **BENT** `BENT-PubMedBERT-NER-Gene`: its model card lists FSU_PRGE
  ("protein", "protein_complex", "protein_familiy_or_group") without
  saying which documents. There is no official split, so BENT has very
  likely seen these documents.

`FSU_PRGE_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/fsu_prge_analytics.py` from the local file and
documents the corpus shape (subcorpora, counts, entity types,
normalization coverage, top mentions).
