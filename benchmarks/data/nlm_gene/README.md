# NLM-Gene - local benchmark data

Only `test.jsonl` is committed to this repo. It is the official held-out
evaluation split, used for testing annotators.

`train.jsonl` is intentionally **not** shipped here (see `.gitignore`).
NLM-Gene does not have a separate validation split.
Anyone who needs the train split can regenerate the full corpus locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/nlm_gene.py
```

That downloads both splits from Hugging Face (`bigbio/nlm_gene`,
config `nlm_gene_bigbio_kb`) into this directory.

NLM-Gene has five entity types (Gene, GENERIF, STARGENE, Domain, Other)
with NCBI Gene normalization. No relations. Documents are PubMed
abstracts (title + abstract).

Note: `Gene`, `GENERIF` and `STARGENE` are all gene mentions. The extra
labels only mark genes with a special role in the article for NLM's gene
indexing, so for NER evaluation they should be merged into one gene type.
`Domain` and `Other` are rare (under 1% of mentions). Like GNormPlus,
NLM-Gene does not distinguish gene from protein mentions, and the corpus
covers many species, not only human.

`NLM_GENE_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/nlm_gene_analytics.py` from a full local download
and documents the entire corpus shape (counts, entity types, merged gene
mentions, normalization coverage, top mentions), even though only the
test split lives here.
