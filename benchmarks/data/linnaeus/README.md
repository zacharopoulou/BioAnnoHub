# LINNAEUS - local benchmark data

LINNAEUS has **no splits**: it is one corpus of 100 documents, and the
Hugging Face loader puts all of them under `train` only because it has to
name a split. So the whole corpus is in `linnaeus.jsonl`, which is
committed to this repo and used for testing annotators, and nothing is
left out via `.gitignore`. To regenerate it locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/linnaeus.py
```

That downloads the corpus through Hugging Face (`bigbio/linnaeus`, config
`linnaeus_bigbio_kb`), which gets the original files from SourceForge.
The loader has two problems, and the script fixes both:

1. **Documents without species are dropped.** 5 of the 100 documents have
   no species mentions, and the loader skips them, returning only 95.
   They still matter for testing, because any species an annotator finds
   in them is a false positive. The script keeps all 100.
2. **Wrong text encoding on Windows.** The text files are UTF-8, but the
   loader opens them with the computer's default encoding (cp1253 on a
   Greek Windows PC), which garbles special characters or crashes. The
   script makes the loader read them as UTF-8.

LINNAEUS has one entity type (species), and every mention is normalized
to an NCBI Taxonomy ID (`db_name` is `ncbi`). No relations.

Notes:

- Documents are **full-text PMC articles**, not abstracts (about 27,500
  characters on average), so annotator runs take longer than on abstract
  corpora.
- Words that only imply a species also count as species mentions, for
  example *patients* or *woman* (human). *patients* is the most common
  mention in the corpus. The original release also has a "filtered" set
  without these words (config `linnaeus_filtered_bigbio_kb`), but the
  full set used here is the standard LINNAEUS benchmark.

`LINNAEUS_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/linnaeus_analytics.py` and documents the corpus
shape (document length, species IDs, entity counts, normalization
coverage, top mentions). On a Windows console that is not UTF-8, run it
with `PYTHONIOENCODING=utf-8`.
