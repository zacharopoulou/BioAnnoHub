# Species-800 - local benchmark data

Only `test.jsonl` is committed to this repo. It is the held-out
evaluation split, used for testing annotators.

`train.jsonl` and `validation.jsonl` are intentionally **not** shipped here
(see `.gitignore`). Anyone who needs them can regenerate the full corpus
locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/species_800.py
```

Unlike most benchmarks here, this one does **not** come from a Hugging Face
loader. The only Hugging Face copy (`spyysalo/species_800`) has sentences
split into IOB tokens, like BC2GM, and drops the character offsets and the
NCBI Taxonomy IDs. So the script builds the corpus itself, in the same
`bigbio_kb` layout as the other benchmarks:

1. **The data** comes from the original S800 release
   (`https://species.jensenlab.org/files/S800-1.0.tar.gz`): 800 PubMed
   abstracts, 100 from each of 8 fields (bacteriology, botany, entomology,
   medicine, mycology, protistology, virology, zoology).
2. **The split** comes from Sampo Pyysalo's S800 repository
   (`https://github.com/spyysalo/s800`, pinned to commit `f5425e7`). It is
   the split most papers use, and the same one as the Hugging Face IOB
   version: 560 train, 80 validation and 160 test abstracts.
3. **Abstracts without species are kept.** 175 of the 800 abstracts (35 in
   test) have no species mentions. They still matter for testing, because
   any species an annotator finds in them is a false positive.

Each document has two passages (title and abstract). Species-800 has one
entity type (Species), and every mention is normalized to an NCBI Taxonomy
ID. No relations.

Notes:

- The original annotation file counts the end offset as part of the
  mention (the last character is included). The script adds 1 to every end
  offset so they work like the other benchmarks. Every mention in the
  output matches its text.
- Mentions often include more than the species name: strain names (for
  example `Streptococcus ratti ATCC 19645`, or just a strain such as
  `YC6903`) and endings such as `sp. nov.`. Higher taxa such as genera and
  families are annotated too. Annotators that tag only the bare species
  name will lose points under strict matching.
- Unlike LINNAEUS, words that only imply a species (such as *patients*)
  are not annotated.

`SPECIES_800_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/species_800_analytics.py` from a full local download
and documents the entire corpus shape (counts, species IDs, span lengths,
normalization coverage, top mentions), even though only the test split
lives here.
