# DDI corpus - local benchmark data

Only `test.jsonl` is committed to this repo. It is the official held-out
drug NER evaluation set, used for testing annotators.

`train.jsonl` is intentionally **not** shipped here (see `.gitignore`).
The DDI corpus does not have a validation split. Anyone who needs the train
split can regenerate the full corpus locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/ddi.py
```

That downloads both splits from Hugging Face (`bigbio/ddi_corpus`, config
`ddi_corpus_bigbio_kb`) into this directory. The loader gets the original
files from GitHub (`https://github.com/isegura/DDICorpus`).

The DDI corpus (Herrero-Zazo et al., 2013) is the corpus of the SemEval
2013 DDIExtraction task, about **drugs and drug-drug interactions**. Its
documents come from two sources: DrugBank drug descriptions (named after
the drug, such as `Abacavir`) and MedLine abstracts (named by PubMed ID).
No normalization. It also has drug-drug interaction relations, which are
kept in the files but are not needed for NER.

## Test set: only the official NER test

The DDI 2013 task had **two different test sets**: one for drug NER
(task 9.1, 112 documents) and one for interaction extraction (task 9.2,
191 documents). The Hugging Face loader puts both into its `test` split
(303 documents). This benchmark is about NER, so the script keeps only
the 112 documents in the `Test for DrugNER task` folder of the original
XML release (pinned to commit `819b0fa`), so that scores can be compared
with published DDI drug NER results. We checked that these 112 documents
have exactly the same entities in the XML release and in the Hugging Face
version (686 entities).

| Split | Documents | Entities |
|---|---|---|
| train | 714 (572 DrugBank, 142 MedLine) | 14,765 |
| test | 112 (54 DrugBank, 58 MedLine) | 686 |

## Entity types

| Type | Meaning | Examples |
|---|---|---|
| DRUG | a drug approved for human use, by its generic name | colchicine, cisplatin, amiodarone |
| BRAND | a brand name of a drug | Chantix, LUCENTIS, MARINOL |
| GROUP | a class or group of drugs | antibiotics, antidepressants, opiate |
| DRUG_N | a substance not approved for human use, such as a toxin or experimental compound | curcumin, apigenin, MPTP |

Notes:

- **For a chemical or drug tagger, all 4 types together are the drugs.**
  GROUP mentions are drug classes, not single substances, so taggers that
  only tag specific chemicals will miss them.
- 24 test documents (mostly MedLine abstracts) have no annotations. They
  are kept, because any drug an annotator finds in them is a false
  positive.
- 1 train mention has a discontinuous span where the text field and the
  text at its offsets differ by a space (`(R)- warfarin`). Test is not
  affected: every test offset matches the text.

## Known training overlap

- **BENT** `BENT-PubMedBERT-NER-Chemical`: its model card lists the DDI
  corpus ("GROUP", "DRUG", "DRUG_N") with **train, dev and test** sets, so
  it has seen this test set. Its scores here are not a fair test.

`DDI_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/ddi_analytics.py` from a full local download and
documents the entire corpus shape (counts, entity types, normalization
coverage, top mentions), even though only `test.jsonl` lives here.
