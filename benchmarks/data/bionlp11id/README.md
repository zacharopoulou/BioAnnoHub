# BioNLP11ID - local benchmark data

Only `test.jsonl` is committed to this repo. It is the official held-out
evaluation split, used for testing annotators.

`train.jsonl` and `validation.jsonl` are intentionally **not** shipped here
(see `.gitignore`). Anyone who needs them can regenerate the full corpus
locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/bionlp11id.py
```

That downloads all three splits from Hugging Face
(`bigbio/bionlp_st_2011_id`, config `bionlp_st_2011_id_bigbio_kb`) into
this directory. The loader gets the original files from
`https://github.com/openbiocorpora/bionlp-st-2011-id`.

BioNLP11ID is the corpus of the BioNLP Shared Task 2011 Infectious
Diseases (ID) task, about how bacteria cause disease. Unlike the other
BioNLP corpora here, its documents are **sections of full-text PMC
articles**, not abstracts: 316 sections from 30 articles (152 sections
from 15 articles in train, 46 from 5 in validation, 118 from 10 in test).
Document IDs look like `PMC1475658-02-Results-03` (article, section
number, section name, paragraph).

It annotates 5 entity types. No normalization.

| Type | Examples |
|---|---|
| Protein | Hfq, SsrB, SpeB |
| Organism | Salmonella, P. entomophila, strain names such as OG1RF or V583 |
| Chemical | LPS, c-di-GMP, iron |
| Two-component-system | CovRS, GacS/GacA (pairs of bacterial signalling proteins) |
| Regulon-operon | flhDC, SpeB operon (groups of bacterial genes) |

Notes:

- **The test set has entities but no events.** ID is an event extraction
  task. The entity annotations (`.a1` files) were given to participants as
  input and only the events were kept hidden, so the test entities are real
  gold annotations and can be used for NER. The `events` field is empty in
  `test.jsonl`.
- **Train and validation have an extra `Entity` type** (28 and 20
  mentions). It comes from the event files (`.a2`) and was only annotated
  when it takes part in an event, so it is not complete and does not
  appear in test. Leave it out when comparing with test.
- **Organism mentions include bacterial strain names** (such as OG1RF),
  which general species taggers often miss.
- One train section and one test section have no annotations. They are
  also empty in the original files, so they are kept.

## Known training overlap

- **BENT**: its model cards list BioNLP11ID for the Gene model (type
  "Gene/protein"), the Chemical model (type "Chemical", **train, dev and
  test** sets) and the Organism model (type "Organism"). The Chemical
  model has seen this test set; the others do not say which splits.

`BIONLP11ID_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/bionlp11id_analytics.py` from a full local download
and documents the entire corpus shape (counts, entity types, normalization
coverage, top mentions), even though only `test.jsonl` lives here.
