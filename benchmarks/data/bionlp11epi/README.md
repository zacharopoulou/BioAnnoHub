# BioNLP11EPI - local benchmark data

Only `test.jsonl` is committed to this repo. It is the official held-out
evaluation split, used for testing annotators.

`train.jsonl` and `validation.jsonl` are intentionally **not** shipped here
(see `.gitignore`). Anyone who needs them can regenerate the full corpus
locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/bionlp11epi.py
```

BioNLP11EPI is the corpus of the BioNLP Shared Task 2011 Epigenetics and
Post-translational Modifications (EPI) task: 1,240 PubMed abstracts (600
train, 200 validation, 440 test) about events such as methylation,
acetylation and phosphorylation of proteins and DNA. Each document is one
passage with the title and abstract together. For NER it has one entity
type, `Protein`, which covers genes and their products. No normalization.

## Where the data comes from

The script uses the Hugging Face loader (`bigbio/bionlp_st_2011_epi`,
config `bionlp_st_2011_epi_bigbio_kb`), which has two problems. The script
fixes both:

1. **There is no test set on Hugging Face.** The loader reads its own
   copy of the data from the Hugging Face repository, but its `test.zip`
   only contains another copy of the training data, so the test split
   comes out empty. The script downloads the original data from GitHub
   (`https://github.com/openbiocorpora/bionlp-st-2011-epi`, pinned to
   commit `9e9b686`) and gives the loader its `train`, `devel` and `test`
   folders. The training split built this way is identical to the Hugging
   Face one, and the test folder's own README confirms it has 440
   abstracts.
2. **Wrong text encoding on Windows.** The loader opens the files with the
   computer's default encoding (cp1253 on a Greek Windows PC) instead of
   UTF-8. The script makes it read them as UTF-8.

## Notes

- **The test set has entities but no events.** EPI is an event
  extraction task. The protein annotations (`.a1` files) were given to
  participants as input and only the events were kept hidden, so the test
  proteins are real gold annotations and can be used for NER. The
  `events` field is empty in `test.jsonl`.
- **Train and validation have an extra `Entity` type** (631 and 213
  mentions). It comes from the event files (`.a2`) and was only annotated
  when it takes part in an event, so it is not complete and does not
  appear in test. Leave it out when comparing with test.

## Known training overlap

- **BENT** `BENT-PubMedBERT-NER-Gene`: its model card lists BioNLP11EPI
  without saying which splits. The test set is not on Hugging Face, but it
  has been public on GitHub, so BENT may still have seen it.

`BIONLP11EPI_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/bionlp11epi_analytics.py` from a full local download
and documents the entire corpus shape (counts, entity types, normalization
coverage, top mentions), even though only `test.jsonl` lives here.
