# MACCROBAT - local benchmark data

MACCROBAT has **no train/test split**: it is one corpus of 200 clinical
case reports. So the whole corpus is in `maccrobat.jsonl`, which is
committed to this repo and used for testing annotators, and nothing is
left out via `.gitignore`. To regenerate it locally:

```
uv run python benchmarks/scripts/maccrobat.py
```

No extra dependencies are needed. MACCROBAT is not part of BigBIO. The
script downloads the original release, **MACCROBAT2020** (Caufield et al.,
figshare, `MACCROBAT2020.zip`, licence CC BY 4.0), and converts its brat
files to the same `bigbio_kb` layout as the other benchmarks.

Each document is one case report from PubMed Central, edited to keep only
the clinical case details, and named by its **PubMed ID** (for example
`15939911`). The whole text is one passage. No normalization. The events
and relations in the original files are not included.

## Why not the Hugging Face copy

An earlier version of this benchmark used the Hugging Face copy
`singh-aditya/MACCROBAT_biomedical_ner`. We compared it with the original
release: it has the same 200 texts, but only 24,795 of the 25,189
annotations (394 were lost in its processing), its types are renamed to
upper case, and the documents lost their PubMed IDs. This version keeps
all 25,189 annotations with their original type names.

## Entity types

MACCROBAT annotates 41 fine-grained clinical types. The most common:

| Type | Mentions | Examples |
|---|---|---|
| Diagnostic_procedure | 4,598 | CT, biopsy, blood pressure |
| Sign_symptom | 3,382 | mass, pain, lesions |
| Biological_structure | 2,953 | chest, abdominal, liver |
| Detailed_description | 2,920 | bilateral, multiple, diffuse |
| Lab_value | 2,848 | normal, negative, positive |
| Disease_disorder | 1,362 | adenocarcinoma, heart failure |
| Medication | 1,080 | chemotherapy, prednisone, diuretics |
| Therapeutic_procedure | 1,036 | resection, surgery, ablation |
| Date | 735 | next day, one year later |
| Clinical_event | 626 | presented, discharged |

The others are History, Severity, Dosage, Nonbiological_location,
Coreference, Duration, Age, Sex, Administration, Distance, Activity,
Family_history, Frequency, Shape, Personal_background, Time, Subject,
Color, Quantitative_concept, Texture, Area, Qualitative_concept, Outcome,
Volume, Other_event, Other_entity, Occupation, Biological_attribute,
Height, Weight and Mass. The full counts are in
`MACCROBAT_ANALYTICS_SUMMARY.md`.

For a disease tagger use `Disease_disorder` (and possibly
`Sign_symptom`), and for a drug tagger use `Medication`. Note that
`Medication` also includes treatments such as *chemotherapy*.

## Notes

- **Spans are trimmed.** A few spans in the original files include a space
  at an edge, often a Unicode space such as U+2005, and one annotation has
  a stray tab after its text. The script moves those offsets in so they
  cover the words only. After this, every mention matches its text.
- **The text has Unicode spaces inside mentions** (for example a thin
  space in `5.94 L`). Offsets are unaffected, but a comparison by text
  should treat all kinds of spaces the same.
- 44 mentions are discontinuous (several pieces of text).

## Known training overlap

MACCROBAT has no split, so any model trained on it has seen these exact
documents, and its score here is **not a fair test**:

- **d4data** (`d4data/biomedical-ner-all`): its model card says it was
  trained on MACCROBAT (linking to the MACCROBAT2018 release), and its
  labels are the MACCROBAT types.
- **Apollo** (`Clinical-AI-Apollo/Medical-NER`): its model card only says
  "the PubMED Dataset", but its 41 labels are exactly the MACCROBAT types
  in upper case, which is the naming of the Hugging Face copy, so it was
  very likely trained on MACCROBAT too.

`MACCROBAT_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/maccrobat_analytics.py` and documents the corpus
shape (counts, entity types, span lengths, top mentions).
