# BioRED - local benchmark data

Only `test.jsonl` is committed to this repo. It is the official held-out
evaluation split, used for testing annotators.

`train.jsonl` and `validation.jsonl` are intentionally **not** shipped here
(see `.gitignore`). Anyone who needs them can regenerate the full corpus
locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/biored.py
```

That downloads all three splits from Hugging Face (`bigbio/biored`,
config `biored_bigbio_kb`) into this directory.

BioRED (Luo et al., Briefings in Bioinformatics 2022) is 600 PubMed
abstracts: 400 train, 100 validation and 100 test. Each document has two
passages (title and abstract) and is named by its PubMed ID.

| Split | Docs | Mentions | Gene | Disease | Chemical | Organism | Variant | Cell line |
|---|---|---|---|---|---|---|---|---|
| train | 400 | 13,351 | 4,430 | 3,646 | 2,853 | 1,429 | 890 | 103 |
| validation | 100 | 3,533 | 1,087 | 982 | 822 | 370 | 250 | 22 |
| test | 100 | 3,535 | 1,180 | 917 | 754 | 393 | 241 | 50 |

The 20,419 mentions in total are the same number as in the BioRED paper,
and every mention matches its text.

## Entity types and normalization

| Type | Normalized to |
|---|---|
| GeneOrGeneProduct | NCBI Gene (`NCBIGene`) |
| DiseaseOrPhenotypicFeature | MeSH (`MESH`), a few OMIM |
| ChemicalEntity | MeSH (`MESH`) |
| OrganismTaxon | NCBI Taxonomy (`NCBITaxon`) |
| SequenceVariant | dbSNP (`dbSNP`), or a tmVar-style description (`custom`) |
| CellLine | Cellosaurus |

- Every mention has at least one ID, but **63 mentions have the ID `-`**,
  meaning the curators found no fitting concept (for example *lectin*,
  *HIV protease*, *SSR103800*). Treat them as unnormalized.
- **529 mentions have more than one ID**, for example *breast and ovarian
  cancer* (two MeSH IDs) or *MODY* tagged as a gene with three NCBI Gene
  IDs.
- Variants without an rs number get a `custom` ID that describes the
  change, for example `c|DEL|4153|A` for *4153delA*.
- *patients* and *mice* are annotated as organisms, so an annotator that
  tags only species names will miss many OrganismTaxon mentions.

## Relations

BioRED annotates relations between concepts (pairs of IDs) in each
abstract, with 8 types: Association, Positive_Correlation,
Negative_Correlation, Bind, Cotreatment, Comparison, Drug_Interaction and
Conversion.

The `bigbio_kb` loader stores each relation once **for every pair of
mentions** of the two concepts, so the files have 128,460 relation rows.
Counted once per document, type and pair of IDs there are about 6,800
(1,134 in test). `BIORED_ANALYTICS_SUMMARY.md` shows both counts. The
original release also marks each relation as novel or not; that flag is
not in the `bigbio_kb` files.

`BIORED_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/biored_analytics.py` from a full local download and
documents the entire corpus shape (counts, entity types, normalization
coverage, relations), even though only the test split lives here.
