# BioNLP13GE - local benchmark data

Only `test.jsonl` is committed to this repo. It is the official held-out
evaluation split, used for testing annotators.

`train.jsonl` and `validation.jsonl` are intentionally **not** shipped here
(see `.gitignore`). Anyone who needs them can regenerate the full corpus
locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/bionlp13ge.py
```

That downloads all three splits from Hugging Face
(`bigbio/bionlp_st_2013_ge`, config `bionlp_st_2013_ge_bigbio_kb`) into
this directory. The loader gets the original files from
`https://github.com/openbiocorpora/bionlp-st-2013-ge`.

BioNLP13GE is the corpus of the BioNLP Shared Task 2013 GENIA Event (GE)
task. Its documents are **sections of full-text PMC articles**, not
abstracts: 776 sections from 34 articles (222 sections from 10 articles in
train, 249 from 10 in validation, 305 from 14 in test). Document IDs look
like `PMC-3585731-22-Materials_and_Methods` (article, section number,
section name). For NER it has one entity type, `Protein`, which covers
genes and their products. No normalization.

Notes:

- **The test set has entities but no events.** GE is an event extraction
  task. The protein annotations (`.a1` files) were given to participants
  as input and only the events were kept hidden, so the test proteins are
  real gold annotations and can be used for NER. The `events` field is
  empty in `test.jsonl`.
- **Train and validation have extra types** that do not appear in test:
  `Entity` (121 and 314 mentions), `Anaphora` (105 and 117, words such as
  *it* that refer back to a protein) and one `Binding` mention in
  validation (an event word that no event uses). They come from the event
  files (`.a2`) and are not complete, so leave them out when comparing
  with test.
- **Many sections have no proteins** (49 of 305 in test), for example some
  *Materials and Methods* or figure caption sections. They are kept,
  because any protein an annotator finds in them is a false positive.
- 2 train annotations include a trailing space in the original files (for
  example `betaI `). The text field drops the space, so their end offset
  is one character longer than the text. Test is not affected: every test
  offset matches the text.

## Known training overlap

- **BENT** `BENT-PubMedBERT-NER-Gene`: its model card lists BioNLP13GE
  (type "Protein") without saying which splits, so it may have seen the
  test set.

`BIONLP13GE_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/bionlp13ge_analytics.py` from a full local download
and documents the entire corpus shape (counts, entity types, normalization
coverage, top mentions), even though only `test.jsonl` lives here.
