# Europe PMC - local benchmark data

Only `test.jsonl` is committed to this repo. It is the held-out
evaluation split, used for testing annotators.

`train.jsonl` and `validation.jsonl` are intentionally **not** shipped here
(see `.gitignore`). Anyone who needs them can regenerate the full corpus
locally:

```
uv run python benchmarks/scripts/europepmc.py
```

No extra dependencies are needed. The Europe PMC corpus is not part of
BigBIO. The script downloads the original release from figshare
(`europepmc-corpus-master.zip`, DOI `10.6084/m9.figshare.22848380.v2`,
licence CC BY 4.0) and converts it to the same `bigbio_kb` layout as the
other benchmarks.

Paper: Yang X. et al., *Europe PMC annotated full-text corpus for
gene/proteins, diseases and organisms*, Scientific Data 10, 722 (2023),
https://www.nature.com/articles/s41597-023-02617-x.

## What is in it

300 **full-text** open access articles from Europe PMC (not only
abstracts), named by their **PMCID** (for example `PMC2474741`). The split
is the one from the release: 210 train, 45 validation and 45 test articles.

| Split | Articles | Mentions | GP | DS | OG |
|---|---|---|---|---|---|
| train | 210 | 51,130 | 25,901 | 9,848 | 15,381 |
| validation | 45 | 9,249 | 3,934 | 2,345 | 2,970 |
| test | 45 | 12,095 | 6,579 | 2,353 | 3,163 |

## Entity types

| Type | Meaning | Curators referred to |
|---|---|---|
| GP | Gene/Protein | UniProt, Protein Ontology |
| DS | Disease | UMLS, EFO |
| OG | Organism | NCBI Taxonomy |

No normalization: the curators used these databases only as a reference,
so no mention has an ID.

## How it is built

- **The source is the release's JSON file**
  (`annotations/JSON/ner_rel_fulltext_full.json`), which has every sentence
  with character offsets. The release also has IOB files, but they are
  tokenized, lose the original spacing and drop 31 of the 72,474 mentions.
- **Each sentence is one passage**, with its section as the passage type
  (`title`, `abs`, `intro`, `methods`, `results`, `discuss`, `table`,
  `fig`, ...; some are two sections joined by a comma, such as
  `results,discuss`). The document text is the sentences joined with one
  space, and all offsets are relative to that text.
- 930 sentences that are only whitespace are dropped. None of them has a
  mention.
- 8 articles (1 in test) have no mentions at all. They are kept, because
  any entity an annotator finds in them is a false positive.

## Notes

- **Tables are a large part of the text but have few mentions.** About a
  third of the passages (37,505 of 113,149) come from tables (cells as
  text), but only about 5% of the mentions (3,921 of 72,474) are in them.
  So an annotator that tags much in table cells (gene symbols, species
  names in column headers) is likely to get false positives there.
- **Gene-disease relations are not included.** The JSON file also marks
  some sentences as having a gene-disease relation (`YGD`), no relation
  (`NGD`) or ambiguous (`AMB`). These are labels for whole sentences, not
  links between two mentions, so they do not fit the `relations` field.
- Every mention in the output matches its text.

`EUROPEPMC_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/europepmc_analytics.py` from a full local download
and documents the entire corpus shape (counts, entity types, span lengths,
top mentions), even though only the test split lives here.
