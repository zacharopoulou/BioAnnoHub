# BioNLP13CG - local benchmark data

Only `test.jsonl` is committed to this repo. It is the official held-out
evaluation split, used for testing annotators.

`train.jsonl` and `validation.jsonl` are intentionally **not** shipped here
(see `.gitignore`). Anyone who needs them can regenerate the full corpus
locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/bionlp13cg.py
```

That downloads all three splits from Hugging Face
(`bigbio/bionlp_st_2013_cg`, config `bionlp_st_2013_cg_bigbio_kb`) into
this directory. The loader gets the original files from
`https://github.com/openbiocorpora/bionlp-st-2013-cg`.

BioNLP13CG is the corpus of the BioNLP Shared Task 2013 Cancer Genetics
(CG) task: 600 PubMed abstracts (300 train, 100 validation, 200 test)
about cancer biology. It annotates 16 entity types, from molecules to
whole organisms: Gene_or_gene_product, Cell, Cancer, Simple_chemical,
Organism, Multi-tissue_structure, Tissue, Cellular_component, Organ,
Organism_substance, Pathological_formation, Amino_acid,
Organism_subdivision, Immaterial_anatomical_entity, Anatomical_system and
Developing_anatomical_structure. No normalization.

Notes:

- **The test set has entities but no events.** CG is mainly an event
  extraction task. In the shared task, the entity annotations (`.a1`
  files) were given to participants as input and only the events (`.a2`
  files) were kept hidden, so the test entities are real gold annotations
  and can be used for NER. The `events` field is empty in `test.jsonl`.
- **Train and validation have 2 extra types:** DNA_domain_or_region and
  Protein_domain_or_region. They come from the event files (`.a2`) and
  were only annotated when they take part in an event, so they are not
  complete and do not appear in test. Leave them out when comparing with
  test.
- **Entities can be nested.** For example the gene `Ink4a` sits inside the
  cell mention `Ink4a/Arf-deficient mouse astrocytes` (87 nested pairs in
  test). The evaluation must allow overlapping gold entities.
- Each document is one passage with the title and abstract together.

`BIONLP13CG_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/bionlp13cg_analytics.py` from a full local download
and documents the entire corpus shape (counts, entity types, normalization
coverage, top mentions), even though only `test.jsonl` lives here.
