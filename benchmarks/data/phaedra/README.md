# PHAEDRA - local benchmark data

Only `test.jsonl` is committed to this repo. It is the official held-out
evaluation split, used for testing annotators.

`train.jsonl` and `validation.jsonl` are intentionally **not** shipped here
(see `.gitignore`). Anyone who needs them can regenerate the full corpus
locally:

```
uv run python benchmarks/scripts/phaedra.py
```

No extra dependencies are needed. The corpus is not on Hugging Face, so the
script downloads the brat files from NaCTeM
(`http://www.nactem.ac.uk/PHAEDRA/PHAEDRA_corpus.tar.gz`) and converts them
to the same `bigbio_kb` layout as the other benchmarks. It checks every
entity offset against the text while converting.

PHAEDRA (Thompson et al., 2018, "Annotation and Detection of Drug Effects
in Text for Pharmacovigilance") is about **pharmacovigilance**: drug
safety, adverse effects and drug-drug interactions. It has 597 PubMed
abstracts with the official split: 359 train, 120 validation (called `dev`
in the corpus) and 118 test. No normalization.

## Entity types

| Type | Meaning | Examples |
|---|---|---|
| Pharmacological_substance | drugs and other substances given to patients | phenytoin, rifampin, placebo |
| Disorder | diseases, symptoms and adverse effects | thrombocytopenia, sepsis, seizures |
| Subject | who is treated or studied | patients, children, human |

For a chemical or drug tagger use `Pharmacological_substance`, and for a
disease tagger use `Disorder`. Note that `placebo` counts as a
pharmacological substance.

## What is left out

The `.a1` files also contain annotations that are not named entities, and
the script leaves them out:

- cue words: `Speculation_cue` (*may*, *possible*), `Negation_cue` and
  `Manner_cue`
- `Coreferring_mention`: words that refer back to another mention, such
  as *he* or *his*
- `Combination`: the word that joins drugs given together, such as *and*,
  *plus* or *combined*

The `.a2` files hold the drug-effect events (adverse effect, potential
therapeutic effect, drug-drug interaction), which are not included.

## Notes

- The text is kept exactly as released: each file starts with some blank
  lines and spaces, and a few train files use Windows line endings. The
  whole text is one passage, so the offsets needed no change. Test is
  plain ASCII.
- 1 train abstract has no entity annotations. It is kept.

## Known training overlap

- **BENT**: its model cards list PHAEDRA for the Disease model (type
  "Disorder") and the Chemical model (type "Pharmalogical_substance"),
  both with **train, dev and test** sets, so both have seen this test set.
  Their scores here are not a fair test.

`PHAEDRA_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/phaedra_analytics.py` from a full local download and
documents the entire corpus shape (counts, entity types, normalization
coverage, top mentions), even though only `test.jsonl` lives here.
