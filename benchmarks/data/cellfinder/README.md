# CellFinder - local benchmark data

Only `test.jsonl` is committed to this repo. It is the held-out evaluation
split, used for testing annotators.

`train.jsonl` is intentionally **not** shipped here (see `.gitignore`).
CellFinder does not have a validation split. Anyone who needs the train
split can regenerate the full corpus locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/cellfinder.py
```

That downloads both splits from Hugging Face (`bigbio/cellfinder`, config
`cellfinder_bigbio_kb`) into this directory. The loader gets the original
files from Humboldt University Berlin.

CellFinder (Neves et al., 2012) is a small corpus about **stem cell
research**: 10 full-text articles, each stored as one document (about
37,000 characters on average). No normalization, no relations.

**Split:** the corpus website does not publish a train/test split. The
split used here is the one defined in the Hugging Face loader: 5 articles
for train and 5 for test, listed by PubMed ID (test: 15971941, 16623949,
16672070, 17288595, 17967047). Scores reported elsewhere may use a
different split.

It annotates 6 entity types:

| Type | Examples |
|---|---|
| CellType | hESCs, macrophages, hCNS-SC |
| GeneProtein | CD34, Nanog, Sox1 |
| Anatomy | liver, and adjectives such as embryonic, neuronal, fetal |
| CellLine | HUES6, NTera2, BG01 |
| Species | human, mouse, HIV-1 |
| CellComponent | extracellular matrix, nuclei, and also RNA, DNA, cDNA |

Notes:

- The loader also has a `cellfinder_splits_bigbio_kb` config with the same
  articles cut into sections. It has exactly the same annotations; the
  whole-article version is used here, as for the other full-text corpora.
- **Adjectives count.** Anatomy mentions include words such as
  *embryonic* or *fetal*, and CellComponent includes *RNA* and *DNA*.
  Taggers that only tag nouns will lose recall here.
- **The download site has bot protection.** The Berlin site sometimes
  answers with a "Making sure you're not a bot!" page instead of the file.
  The Hugging Face loader got through when this benchmark was built, but a
  plain download (for example with curl) was blocked. If the script fails
  on download, that is the likely reason; `test.jsonl` is committed here,
  so the test set does not depend on the site.
- 5 test articles is a small test set (3,185 mentions), so scores will
  vary more than on the larger benchmarks.

## Known training overlap

- **BENT**: its model cards list CellFinder for the Gene ("GeneProtein"),
  Organism ("species"), Anatomical ("Anatomical parts"), Cell-Type
  ("CellType") and Cell-Line ("CellLine") models, without saying which
  articles. With only 10 articles, BENT has very likely seen some of
  these test articles.

`CELLFINDER_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/cellfinder_analytics.py` from a full local download
and documents the entire corpus shape (counts, entity types, normalization
coverage, top mentions), even though only `test.jsonl` lives here.
