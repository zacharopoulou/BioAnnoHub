# MedMentions - local benchmark data

Only the two **test** files are committed to this repo, used for testing
annotators: `st21pv_test.jsonl` (7.3 MB) and `full_test.jsonl` (12.5 MB).
The train and validation files are intentionally **not** shipped here (see
`.gitignore`). Anyone who needs them can regenerate the full corpus
locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/medmentions.py
```

That downloads both versions from Hugging Face (`bigbio/medmentions`,
configs `medmentions_st21pv_bigbio_kb` and `medmentions_full_bigbio_kb`)
into this directory. The loader gets the original files from GitHub
(`https://github.com/chanzuckerberg/MedMentions`) and reads them as UTF-8,
so there are no encoding issues on Windows. Every entity offset matches
the text.

MedMentions (Mohan and Li, 2019, Chan Zuckerberg Initiative) has **4,392
PubMed abstracts** from 2016, with every mention of a **UMLS concept**
annotated and linked to its UMLS CUI (for example `C0162638`). It uses the
official split: 2,635 train, 878 validation and 879 test abstracts. Each
document has a title passage and an abstract passage.

## Two versions

| Version | Files | Types | Test mentions |
|---|---|---|---|
| **st21pv** | `st21pv_*.jsonl` | 21 UMLS semantic types | 40,157 |
| full | `full_*.jsonl` | 127 UMLS semantic types | 76,861 |

- **st21pv** ("21 semantic types, preferred vocabularies") is the version
  the authors recommend as a benchmark, and the one scispaCy reports on.
  Mentions are limited to 21 broad semantic types and to concepts from a
  set of preferred vocabularies, and each mention's type is the one of
  those 21 that its concept falls under.
- **full** keeps every UMLS mention, with its specific semantic type.

Both versions use the same abstracts and split.

## Notes for evaluation

- **The st21pv types are broad parent types, not the usual NER types.**
  Diseases are inside `T038` Biologic Function, mixed with processes such
  as *expression*. Proteins and genes are inside `T103` Chemical. Species
  are split over `T204`, `T007` and `T005`. So a disease, gene or chemical
  tagger cannot be scored on one type without also being counted wrong for
  everything else in that type. The UMLS CUIs can be used to pick out
  diseases (or other groups) more precisely.
- **Very general words are annotated**, such as *study*, *treatment*,
  *women* or *findings*. NER tools that tag only names will get low recall
  on MedMentions as a whole.
- For linking, the CUIs are from UMLS 2017AA.

## Known training overlap

- **scispaCy**: its general models (`en_core_sci_md`, `en_core_sci_scibert`)
  have NER trained on MedMentions, and the scispaCy authors report on the
  st21pv test set. Their test score is fair only if the models were not
  trained on the test split.
- **BENT**: MedMentions is not in BENT's training list.

`MEDMENTIONS_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/medmentions_analytics.py` from a full local download
and documents both versions and all splits (counts, entity types,
normalization coverage, and top mentions per type for st21pv).
