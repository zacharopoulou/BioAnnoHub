# SCAI Disease - local benchmark data

The SCAI Disease corpus ("Corpus for Disease Names and Adverse Effects",
Gurulingappa et al., 2010) has **no splits**: it is one corpus of 400
documents, and the Hugging Face loader puts all of them under `train` only
because it has to name a split. So the whole corpus is in
`scai_disease.jsonl`, which is committed to this repo and used for testing
annotators, and nothing is left out via `.gitignore`. To regenerate it
locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/scai_disease.py
```

That downloads the corpus from Hugging Face (`bigbio/scai_disease`, config
`scai_disease_bigbio_kb`) into this directory. The loader gets the original
file from Fraunhofer SCAI. That file is plain ASCII, so reading it on
Windows is safe.

The corpus has 400 randomly selected PubMed abstracts found with the query
"Disease OR Adverse effect". Each document is one passage with the title
and abstract together. No normalization, no relations.

It annotates 2 entity types:

| Type | Meaning | Examples |
|---|---|---|
| DISEASE | diseases | cancer, breast cancer, COPD, ALL |
| ADVERSE | adverse effects, usually of a drug or treatment | cytotoxicity, headache, neutropenia |

Notes:

- **For a disease tagger, DISEASE and ADVERSE together are the diseases.**
  An adverse effect such as *neutropenia* is still a disease or symptom;
  the type only says that it was caused by a drug or treatment in that
  text. Most NER tools will tag both as diseases.
- 70 abstracts have no annotations. They are kept, because any disease an
  annotator finds in them is a false positive.
- 1 mention has a double space in the text (`neurological  disorder`), so
  its text field differs from the text at its offsets by that one space.

## Known training overlap

- **BENT** `BENT-PubMedBERT-NER-Disease`: its model card lists this corpus
  ("DISEASE", "ADVERSE") with **train, dev and test** sets. The corpus has
  no official split, so BENT made its own and has seen at least part of
  these documents. Its scores here are not a fair test.

`SCAI_DISEASE_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/scai_disease_analytics.py` and documents the corpus
shape (counts, entity types, normalization coverage, top mentions).
