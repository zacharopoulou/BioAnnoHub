# DNA Methylation - local benchmark data

Only `develtest.jsonl` is committed to this repo. It is the public held-out
set, used for testing annotators.

`train.jsonl` is intentionally **not** shipped here (see `.gitignore`).
Anyone who needs it can regenerate the full corpus locally:

```
uv run python benchmarks/scripts/dna_methylation.py
```

No extra dependencies are needed. The corpus is not on Hugging Face, so the
script downloads the original brat standoff files from GitHub
(`https://github.com/openbiocorpora/dna-methylation`, pinned to commit
`cbc076e`) and converts them to the same `bigbio_kb` layout as the other
benchmarks. It checks every entity offset against the text while
converting.

The DNA Methylation corpus (Ohta et al., 2011, "Event Extraction for DNA
Methylation") is an event corpus from the GENIA project about **DNA
methylation of genes**, mostly in cancer. Each document is a PubMed
abstract with a title passage and an abstract passage. For NER it has one
entity type, `Protein`, which covers genes and their products (for example
p16, RASSF1A, E-cadherin). No normalization.

## Splits: no official test set

The corpus README says it contains only the **"non-blinded subsets"**:
the real test set was never released. What is public is:

| Split | Documents | Proteins |
|---|---|---|
| train | 100 | 1,486 |
| develtest | 34 | 478 |

`develtest` is the development/test set given to researchers, so it is the
held-out set here. The file keeps its original name, `develtest.jsonl`,
instead of `test.jsonl`, because it is not the official test set.

## Notes

- **Only the `.a1` Protein annotations are used.** The `.a2` files hold
  the methylation events and an extra `Entity` type (for example CpG
  islands or promoters) that was only annotated when it takes part in an
  event, so it is not complete. Neither is included.
- 1 develtest abstract and 3 train abstracts have no proteins. They are
  kept, because any protein an annotator finds in them is a false positive.
- The text is plain ASCII, so there are no encoding issues.
- 34 documents is a small test set, so scores will vary more than on the
  larger benchmarks.

## Known training overlap

- **BENT** `BENT-PubMedBERT-NER-Gene`: its model card lists the DNA
  Methylation corpus without saying which splits. Only train and develtest
  are public, so BENT has very likely seen `develtest`.

`DNA_METHYLATION_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/dna_methylation_analytics.py` from a full local
download and documents the entire corpus shape (counts, entity types,
normalization coverage, top mentions), even though only `develtest.jsonl`
lives here.
