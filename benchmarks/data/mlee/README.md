# MLEE - local benchmark data

Only `test.jsonl` is committed to this repo. It is the official held-out
evaluation split, used for testing annotators.

`train.jsonl` and `validation.jsonl` are intentionally **not** shipped here
(see `.gitignore`). Anyone who needs them can regenerate the full corpus
locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/mlee.py
```

That downloads all three splits from Hugging Face (`bigbio/mlee`, config
`mlee_bigbio_kb`) into this directory. The loader gets the original files
from NaCTeM (`MLEE-1.0.2-rev1.tar.gz`). The text is plain ASCII, so there
are no encoding issues on Windows, and every entity offset matches the
text.

MLEE (Multi-Level Event Extraction, Pyysalo et al., 2012) is an event
corpus from NaCTeM about **angiogenesis** (the growth of new blood vessels,
for example in tumors). It has 262 PubMed abstracts (131 train, 44
validation, 87 test). Each document is one passage with the title and
abstract together. No normalization. The events, relations and
coreferences are kept in the files but are not needed for NER.

It annotates 16 entity types, from molecules up to whole organisms. The
most common ones:

| Type | Examples |
|---|---|
| Gene_or_gene_product | VEGF, IL-8, p53 |
| Pathological_formation | tumor, cancer, gliomas |
| Cell | endothelial cells, pericyte |
| Drug_or_compound | heparin, DMBA, NO |
| Organism | human, mice, patients |
| Multi-tissue_structure | blood vessels, vasculature |
| Tissue | microvessel, connective tissue |

The others are Organ, Cellular_component, Organism_substance,
Organism_subdivision, Anatomical_system, Immaterial_anatomical_entity,
Developing_anatomical_structure, DNA_domain_or_region and
Protein_domain_or_region.

Notes:

- **There is no Disease type.** Tumors and cancers are
  `Pathological_formation`, so for a disease tagger use that type (it
  only covers tumor-like diseases, not diseases in general).
- The types are the same scheme as BioNLP13CG (both come from the same
  group at NaCTeM), so results on the two corpora can be compared type by
  type.
- Unlike the BioNLP shared task corpora, MLEE was released complete, so
  its test set also has the events.
- 1 train abstract has no annotations. It is kept.

## Known training overlap

- **BENT**: its model cards list MLEE for the Gene model
  ("Gene_or_gene_product"), the Chemical model ("Drug or compound",
  **train, dev and test** sets), the Organism model ("organism"), the
  Anatomical model (anatomy types) and the Cell-Component model
  ("Cellular_component"). The Chemical model has seen this test set; the
  others do not say which splits.

`MLEE_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/mlee_analytics.py` from a full local download and
documents the entire corpus shape (counts, entity types, normalization
coverage, top mentions), even though only `test.jsonl` lives here.
