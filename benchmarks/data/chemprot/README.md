# ChemProt - local benchmark data

Only `test.jsonl` is committed to this repo. It is the official held-out
evaluation split, used for testing annotators.

`train.jsonl` and `validation.jsonl` are intentionally **not** shipped here
(see `.gitignore`). Anyone who needs them can regenerate the full corpus
locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/chemprot.py
```

That downloads all three splits from Hugging Face (`bigbio/chemprot`,
config `chemprot_bigbio_kb`) into this directory. The data is stored on
Hugging Face itself (as Parquet files), so the download does not depend on
the BioCreative website.

ChemProt is the corpus of the BioCreative VI Chemical-Protein interaction
task (track 5): 2,432 PubMed abstracts (1,020 train, 612 validation, 800
test) about how chemicals act on proteins, for example as activators or
inhibitors. Each document is one passage with the title and abstract
together. No normalization. It also has chemical-protein relations, which
are kept in the files but are not needed for NER.

It annotates 3 entity types:

| Type | Meaning | Examples |
|---|---|---|
| CHEMICAL | chemicals and drugs | glucose, ATP, dopamine |
| GENE-Y | a gene or protein that can be linked to a database entry | COX-2, EGFR, ERα |
| GENE-N | a gene or protein that cannot be linked, such as a family or a generic term | kinase, cytokines, Akt |

Notes:

- **For a gene tagger, GENE-Y and GENE-N together are the genes.** The
  split between them depends on the context, not the word: *insulin*, for
  example, appears as both.
- The Hugging Face dataset also has a small `sample` split (50 abstracts,
  12 of them also in train). It is only a demo and is not used here.

## Known training overlap

- **BENT**: its model cards list ChemProt for the Gene model (types
  "GENE-Y", "GENE-N") and the Chemical model (**train, dev and test**
  sets). The Chemical model has seen this test set; the Gene model card
  does not say which splits.

`CHEMPROT_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/chemprot_analytics.py` from a full local download and
documents the entire corpus shape (counts, entity types, normalization
coverage, top mentions), even though only `test.jsonl` lives here.
