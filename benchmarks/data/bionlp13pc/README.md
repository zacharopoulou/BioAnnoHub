# BioNLP13PC - local benchmark data

Only `test.jsonl` is committed to this repo. It is the official held-out
evaluation split, used for testing annotators.

`train.jsonl` and `validation.jsonl` are intentionally **not** shipped here
(see `.gitignore`). Anyone who needs them can regenerate the full corpus
locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/bionlp13pc.py
```

That downloads all three splits from Hugging Face
(`bigbio/bionlp_st_2013_pc`, config `bionlp_st_2013_pc_bigbio_kb`) into
this directory. The loader reads a copy of the data stored in the Hugging
Face repository. We compared it with the original files
(`https://github.com/openbiocorpora/bionlp-st-2013-pc`): all three splits
have the same documents, identical text and the same number of entities.

BioNLP13PC is the corpus of the BioNLP Shared Task 2013 Pathway Curation
(PC) task: 525 PubMed abstracts (260 train, 90 validation, 175 test) about
molecular pathways, meaning how molecules act on each other inside the
cell. Each document is one passage with the title and abstract together.
No normalization.

It annotates 4 entity types:

| Type | Examples |
|---|---|
| Gene_or_gene_product | p53, E2F, Wnt |
| Complex | NF-kappaB, mTORC1, IKK |
| Simple_chemical | LPS, cAMP, Na+ |
| Cellular_component | nucleus, chromatin, mitochondrial |

Notes:

- **The test set has entities but no events.** PC is an event extraction
  task. The entity annotations (`.a1` files) were given to participants as
  input and only the events were kept hidden, so the test entities are
  real gold annotations and can be used for NER. The `events` field is
  empty in `test.jsonl`.
- Unlike the other BioNLP corpora here, all splits have the same 4 types
  (no extra types from the event files).
- **Protein complexes are a separate type.** Names such as *NF-kappaB* are
  `Complex`, not `Gene_or_gene_product`. When scoring a gene tagger,
  decide whether complexes count as genes, because many taggers tag them.

## Known training overlap

- **BENT** `BENT-PubMedBERT-NER-Gene`: its model card lists BioNLP13PC
  (type "Gene_or_gene_product") without saying which splits, so it may
  have seen the test set.

`BIONLP13PC_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/bionlp13pc_analytics.py` from a full local download
and documents the entire corpus shape (counts, entity types, normalization
coverage, top mentions), even though only `test.jsonl` lives here.
