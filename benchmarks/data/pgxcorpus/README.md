# PGxCorpus - local benchmark data

PGxCorpus has **no train/test split** (its authors used cross-validation).
So the whole corpus is in `pgxcorpus.jsonl`, which is committed to this
repo and used for testing annotators, and nothing is left out via
`.gitignore`. To regenerate it locally:

```
uv run python benchmarks/scripts/pgxcorpus.py
```

No extra dependencies are needed. The corpus is not on Hugging Face, so the
script downloads the brat files (`PGxCorpus.tar`) from GitHub
(`https://github.com/practikpharma/PGxCorpus`, pinned to commit
`067513c`) and converts them to the same `bigbio_kb` layout as the other
benchmarks. It checks every entity offset against the text while
converting.

PGxCorpus (Legrand et al., 2020, Scientific Data) is about
**pharmacogenomics**: how genetic variation changes the way people respond
to drugs. It has **945 sentences** taken from 911 PubMed abstracts; each
document is one sentence, named `<PMID>_<sentence number>`. Each sentence
was annotated by 2 annotators and then checked by a senior annotator. No
normalization. It also has relations between entities, which are not
included here.

## Entity types

| Type | Mentions | Examples |
|---|---|---|
| Chemical | 1,718 | warfarin, tacrolimus, alcohol |
| Gene_or_protein | 1,708 | EGFR, CYP3A5, CYP2C9 |
| Limited_variation | 919 | rs9923231, EGFR mutations, polymorphisms |
| Phenotype | 699 | apoptosis, survival, progression-free survival |
| Disease | 635 | breast cancer, NSCLC, alcohol dependence |
| Pharmacodynamic_phenotype | 632 | myelosuppression, toxicity, response |
| Pharmacokinetic_phenotype | 160 | clearance, metabolism, MTX clearance |
| Haplotype | 137 | CYP2C19 * 2, HLA-B * 5701 |
| Genomic_factor | 99 | 5-HTTLPR, EGFR exon 19 |
| Genomic_variation | 54 | MLL abnormalities, dopamine knockouts |

For a variant tagger, `Limited_variation`, `Haplotype` and
`Genomic_variation` are the variants.

## Notes

- **Entities are heavily nested** (3,975 nested pairs). Phrase-level types
  contain the names inside them: `iNOS - / -` (Limited_variation) contains
  `iNOS` (Gene_or_protein), and `levels of estrone`
  (Pharmacodynamic_phenotype) contains `estrone` (Chemical). The
  evaluation must allow overlapping gold entities, and a name tagger will
  only match the inner mention.
- **The text is pre-tokenized.** The sentences come with spaces around
  punctuation (`Among controls , we found ...`, `CYP2C19 * 2`), as they
  were released.
- **Mention text comes from the offsets.** About half of the annotations
  in the original files have an extra space at the end of their text field
  (`estrone ` while the offsets cover `estrone`). The offsets are correct,
  so the script takes the mention text from them.
- 409 mentions are discontinuous (several pieces of text).
- The sentences were chosen because they mention pharmacogenomic
  relations, so every sentence has annotations.

## Known training overlap

- **BENT**: its model cards list PGxCorpus for the Gene model
  ("Gene_or_protein"), the Disease model (**train, dev and test** sets),
  the Chemical model ("Chemical", **train, dev and test** sets) and the
  Variant model ("Limited_variation"). There is no official split, so BENT
  made its own and has seen at least part of these sentences.

`PGXCORPUS_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/pgxcorpus_analytics.py` and documents the corpus
shape (counts, entity types, normalization coverage, top mentions).
